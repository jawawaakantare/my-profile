# my-profile

自分用のSNSリンクと簡易ポートフォリオをまとめた、1ページのプロフィールサイトです。
HTML / CSS / JavaScriptだけで動きます。npmやフレームワークの準備は必要ありません。

## 見る方法

`index.html` をダブルクリックして、ブラウザーで開いてください。
編集を保存したら、ブラウザーを再読み込みすると変更が表示されます。
この段階では自分のパソコンで見ることができます。SNSからリンクするには、別途サイトを公開する必要があります。

## 自分の情報に変更する

1. `index.html` をエディターで開き、`じゃわわ (あかんたれ)`の名前、自己紹介を書き換えます。自己紹介の `<br>` が改行です。タブのタイトルやページの説明、ヘッダー、フッターの名前も変更できます。
2. SNSリンクは実際のプロフィールURLを設定済みです。表示順はX → Instagram → Spotify → YouTube → GitHub → Discordで、すべて新しいタブで開きます。変更するときは、それぞれの `href="..."` を編集します。アイコンはHTML内のSVGなので、外部ライブラリは不要です。
3. プロフィール画像は `assets/profile.jpg` を表示しています。差し替えるときは同じファイル名で画像を置き換えます。`border-radius: 50%` と `object-fit: cover` で、縦横比を保ったまま円形にトリミングします。別のファイル名を使う場合は `index.html` の `src` を変更し、`alt` の説明も画像に合わせます。
4. Worksは現在、準備中の見本です。作品ができたら、タイトル・説明を編集し、`<a href="作品のURL">作品を見る</a>` をカード内に追加します。カードを増やす場合は、`<article class="work-card">` から対応する `</article>` までをコピーします。
5. 色を変更するときは、`style.css` の先頭にある `--accent`（アクセント色）や `--background`（背景色）を編集します。

## レイアウト

ページの順番はプロフィール → Find me online → Photo Gallery → Worksです。
自己紹介は15pxの文字と広めの行間で表示し、`<br>` で指定した改行を保ちます。
初期表示では最初の2行だけを表示し、「その他」で残りを展開、「閉じる」で折りたたみます。開閉状態は保存しません。ボタンはEnter・Spaceでも操作でき、非表示部分は読み上げ・フォーカスの対象から外れます。「動きを減らす」設定では即座に開閉します。JavaScriptが無効の場合は全文を表示します。
小さい画面ではWorksを縦1列に、幅560px以上では2列に表示します。
SNSは幅700px以上で2列の接続スロット、スマートフォンでは1列に表示します。画面幅に合わせ、ページ幅は最大800pxです。
外部フォントや画像のダウンロードは不要で、JavaScriptが無効でも本文とリンクは表示されます。

## ライトモード・ダークモード

手動で選択していない間は、OSやブラウザーの外観設定に合わせて配色を自動で切り替えます。ヘッダー右側の☀／☾ボタンは、クリック・タップ・Enter・Spaceで操作できます。選択したテーマは `localStorage` の `jawawa-theme` に保存し、次回アクセス時にもOS設定より優先します。保存が禁止されている環境でも、そのページ内の切り替えは使えます。
ライトモードは白〜淡い水色、ダークモードは濃紺を基調にしています。
シアン・マゼンタ・パープルを、ロゴや見出し、SNSボタン、Worksの装飾に使っています。
本文は落ち着いた色を保ち、カードの枠線とホバーに控えめなネオングローを加えています。
レイアウトはどちらのモードでも同じです。

`theme.js` をCSSより先に読み込み、保存済みテーマを初期表示から適用します。`style.css` の先頭の `:root` がライトモード、`:root[data-theme="dark"]` がダークモードの色です。JavaScriptが無効の場合もCSSでOS設定に追従します。切り替え時は対応ブラウザーで背景を含めてクロスフェードし、その他のブラウザーでは主要な色を滑らかに切り替えます。
OS設定への追従を再確認するには、保存した `jawawa-theme` をブラウザーの開発者ツールで削除して再読み込みしてください。

`--accent`・`--magenta`・`--purple` は文字やアイコン用の色、
`--neon-` で始まる色は鮮やかな装飾用の色です。
ライトモードの文字には濃いアクセントカラーを使い、白背景でも読めるようにしています。
動きを減らす端末設定ではホバーの移動と切り替えアニメーションを省きます。

## 背景の演出

淡い空色（ライト）／濃紺（ダーク）の固定背景に、45度傾けた大小の半透明パネルと、非対称に重なるワイヤーフレームのひし形を配置しています。薄いグリッド、光の粒子、シアン〜白の光の帯を重ね、パネルとワイヤーは別方向・別速度でゆっくり漂います。一部の辺には控えめな光線が流れます。2000年代前半のデジタルフューチャーをイメージしたオリジナルのCSS表現です。背景はスクロールから独立して、レイヤーごとに異なる速度でゆっくり動きます。本文の背面には薄い幕を置き、文字の読みやすさを保っています。

装飾のHTMLは `index.html` の `ambient-background`、色・配置・速度は `style.css` 末尾の同名セクションで調整できます。画像素材や追加のJavaScriptは不要です。スマートフォンでは粒子とレイヤー数を減らし、端末の「動きを減らす」設定では背景アニメーションを停止します。背景は操作や読み上げの対象にはなりません。SNS・Worksカードには対角の小さな角のカットと細いシアンのライン、セクション見出しにはひし形の装飾を加えています。内容・カードの寸法・ギャラリーの写真枠は維持しています。

## 小さなデジタルディテール

各セクションに架空のシステムラベル、細い区切り線、大小・塗りつぶしの異なる小さなひし形を添えています。これらのステータスは装飾専用で、実際の接続状態を示すものではありません。ギャラリーの写真数は `tomogashimaPhotos` から自動で更新します。ランプと短いラインは14〜18秒周期で穏やかに動きます。

PCでは `details.js` が既存の背景レイヤーをラップし、スクロールに応じて最大16px／6px／3pxだけ動かします。既存の浮遊アニメーションとは別の親レイヤーで合成し、カルーセルとテーマ切り替えには触れません。スマートフォンでは縦長画面用にひし形のサイズ・位置を組み直し、左右と縦方向に大小のパネル・ワイヤー、細い座標線と極薄のシステム表示を分散させています。背景は固定なのでページ下部でも模様が残り、スクロール連動は最大8px／3px／1.5pxに抑えます。辺の光線や手前のグリッドは省き、2層のゆっくりした浮遊だけを維持します。「動きを減らす」設定ではパララックス、ランプ、ラインの動きを止めます。

## プロフィールのページ内ナビゲーション

自己紹介の下のNETWORK／PHOTO STREAM／WORK ARCHIVEパネルから、各セクションへ移動できます。標準のアンカーリンクを使い、再読み込みせず滑らかにスクロールします。見出しの上にPCで42px、スマートフォンで34pxの余白を残します。ページ末尾のWorksでは、スクロール可能な範囲で移動します。

リンクはTabで選択し、Enterで移動できます。JavaScriptが無効でも移動できます。`navigation.js` は操作時の細い光のラインだけを補い、スクロール自体には介入しません。端末の「動きを減らす」設定では即座に移動し、パネルの浮き上がりや光のアニメーションも省きます。

## 統一されたデジタル端末UI

`system.css` を既存のCSSの後に読み込み、プロフィール、ヘッダー、SNS、ギャラリー、Worksを、45度の角・銀色の帯・薄い二重枠・チャンネル番号で統一しています。ライトは淡い水色のガラス、ダークは青緑と濃紺の機器パネルです。背景のひし形は維持し、極薄の横走査線と遅い斜めのラインを加えています。既存作品の画像・ロゴ・UI素材は使いません。

MODE SELECTパネルはホバー／キーボードフォーカスで横方向に少し展開し、装飾ステータスがSTANDBYからACTIVEへ変わります。操作時は細い光線を一度だけ流します。スマートフォンでは縦3列の押しやすいパネルにし、端のHUDや一部のシステム情報は省きます。ギャラリーの情報欄は写真の上部にまとめ、写真の縦横比・高さ・無限ループ処理は維持しています。

`system.js` はIntersectionObserverで各セクションを監視します。最初に画面へ入ったときだけ、ライン→ひし形→フレーム→本文を約520msで表示し、監視を解除します。未表示セクションを常時非表示にはしないため、JavaScript無効時・監視API非対応時も内容を読めます。「動きを減らす」設定では表示シーケンス、パネルの移動、背景の動きを省きます。

## Photo Gallery：写真を差し替える

「Tomogashima / 友ヶ島」は `assets/gallery/tomogashima/` の実際の写真8枚を使用しています。
`script.js` の `tomogashimaPhotos` に登録した写真をファイル名順に表示します。
ブラウザーからフォルダー内のファイル一覧は取得しないため、写真を入れるだけでは増えません。

1. 写真を `assets/gallery/tomogashima/` フォルダーに入れます。
2. `script.js` の先頭付近にある `tomogashimaPhotos` の `src` に、そのファイルの場所を登録します。
3. `alt` と `caption` で各写真の説明を変更します。
4. 保存してブラウザーを再読み込みしてください。

元のファイル名を使いたい場合やPNG・WebP画像を使う場合は、`src` を実際のファイル名に合わせます。
拡張子も合わせてください。例：`assets/gallery/tomogashima/sea.webp`。
`alt` は写真を見られない人にも内容が伝わる説明、`caption` は写真の下に表示する短い説明です。
横長・縦長どちらの写真も、切り抜かずに全体を表示します。
スマートフォンで読み込みやすくするため、写真は長辺2000px程度に縮小し、1枚1MB程度以下を目安にすると扱いやすくなります。

## 写真を追加・削除・並べ替える

写真を追加するときは、画像をフォルダーに入れ、`script.js` の `tomogashimaPhotos` の `[` と `]` の間に次のような1行を追加します。

```js
{ src: "assets/gallery/tomogashima/1000003530.jpg", alt: "木々の間から見える友ヶ島の海", caption: "木漏れ日と海" },
```

行末のカンマ `,` を残してください。写真列とループ用の複製は自動で更新されます。
削除するときは、その写真の `{ src: ... },` の行を丸ごと削除します（画像ファイルは残しても構いません）。
表示順はファイル名で自動ソートするため、追加する行の位置は自由です。順番を変えたいときは画像のファイル名と `src` を合わせて変更します。
通常の追加・削除ではHTMLやCSSの編集は不要です。先頭の写真を変更・削除する場合だけ、`index.html` 内の `gallery-stage` と `photo-enlarged` の画像の `src` と `alt` も、新しい先頭の写真に合わせてください（JavaScript無効時の表示用です）。
1枚だけの場合は自動スクロールを無効にし、0枚の場合は「写真は準備中です。」と表示します。

## ギャラリーの操作

- 複数の写真を横一列に並べ、右から左へ一定速度で流します。写真列を複製し、最後から最初へも継ぎ目なくつながります。1周は約50秒です。
- マウスのドラッグ・左右スワイプ・ギャラリー内の左右矢印キーで手動移動できます。縦方向のスワイプはページスクロールに使えます。
- マウスを重ねている間、タッチ・ドラッグ中、キーボードで操作している間、拡大中、別タブ表示中、写真が画面外にある間は自動スクロールを停止します。操作後は停止条件がなくなってから約3秒待って再開します。
- 「一時停止」で自動スクロールを止め、「再生」で再開できます。
- 写真をタップ／クリックすると、その写真を拡大します。閉じるボタン・Escキー・画面外側の背景クリックで戻れます。ドラッグ／スワイプでは拡大しません。
- 端末の「動きを減らす」設定では自動スクロールを停止し、手動操作だけにします。この設定中は「再生」ボタンも無効です。

速度を変える場合は、`script.js` の `const loopSeconds = 50;` を変更します。40〜60秒を目安に、数字を大きくするとゆっくりになります。操作後の待ち時間は `const resumeDelay = 3000;`（ミリ秒）で調整できます。
